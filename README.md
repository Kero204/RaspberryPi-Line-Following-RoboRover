# Raspberry Pi Line Follower Robot

Projekt til Udvidede indlejrede systemer.

## Formål

Robotten skal følge en bane markeret med sort tape ved hjælp af:

- Raspberry Pi
- Motor driver
- 2 DC-motorer
- IR-sensorer
- Python

## Projektstruktur

- `src/` - Python-kode
- `docs/` - hardware og GPIO-dokumentation
- `setup/` - scripts til opsætning af Raspberry Pi
- `requirements.txt` - Python dependencies

## Kørsel

Python-koden placeres i `src/`.
